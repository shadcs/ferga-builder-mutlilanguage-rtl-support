# Security policy

Please **do not** open a public issue for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** on this repository. You'll get a reply as soon as possible, and a fix will be released before details are published.

Supported versions: the latest minor release.

Note: rich text, headings and other block content are written by your panel's users and rendered on your site. Only give page-editing access to people you trust, as you would for any CMS.
